## Stuff I Build

A few examples from my repos:

- **[Bitcoin Easy Signer](https://github.com/cjtsh/bitcoin-easy-multisig-signer)**  
  Open-source desktop software that helps a trusted person make a payment from an existing Bitcoin multisig wallet. Maintained and distributed by Bitseeker LLC.

- **[mac-mlx-control-center](https://github.com/cjtsh/mac-mlx-control-center)**  
  1-click control center for local MLX LLM workflows on Apple Silicon.

- **[wireguard-orchestrator](https://github.com/cjtsh/wireguard-orchestrator)**  
  Web dashboard to deploy/manage multi-node WireGuard networks over SSH.

- **[opencode-search-plugin](https://github.com/cjtsh/opencode-search-plugin)** / **[pi-search-plugin](https://github.com/cjtsh/pi-search-plugin)**

- **[wireguard-vpn-server-installer-ubuntu-linux](https://github.com/cjtsh/wireguard-vpn-server-installer-ubuntu-linux)**  
  One-click-ish WireGuard server setup script for Ubuntu VPS.

- **[wireguard-vpn-connection-manager-ubuntu-linux](https://github.com/cjtsh/wireguard-vpn-connection-manager-ubuntu-linux)**  
  Small CLI utility for managing client-side VPN connections.
